## How to Add Videos

1. Go to your Shopify theme editor
2. Add the "Video Gallery" section to your page
3. For each video:
   - Click "Add block" → "Video"
   - Paste the YouTube URL in the "Video URL" field
   - Add the description text in the "Description" field
   - Optionally add a title
